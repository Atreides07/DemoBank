# Иллюстрации банка

Оригинальные изображения, созданные ImageGen для демонстрационного приложения по направлению пользовательских референсов. Персональные снимки, реквизиты и логотипы реального банка сюда не включены. В приложение включены WebP без потерь: размеры и RGBA-пиксели совпадают с исходными PNG. Размеры и SHA поставляемых WebP — в `artworks.json`.

Пакет подключают только `bank_experience` и каталог через него. `design_system` получает источник через `DsArtworkSource`; приложение штрафов не зависит от этого пакета и не включает маркетинговые изображения в APK. Компоненты декодируют изображения под ширину отображения и DPR с верхней границей, а длинная витрина строится лениво.
