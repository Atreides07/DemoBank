# Дизайн-система DemoBank

Пакет: `packages/design_system`. Публичный вход: `package:design_system/design_system.dart`. Пакет зависит от Flutter и `qr_flutter` для локального построения QR; не знает о сетевом транспорте, деньгах как предметной модели, BLoC, поставщиках платежей и приложении DemoBank.

## Модель визуальных решений

Четыре уровня образуют единый контракт:

1. Базовая шкала и геометрия находятся в `src/tokens.dart`, палитры и типографика — в `src/theme.dart`.
2. Семантические варианты: `DsSpace`, `DsInset`, `DsTextStyle`, `DsTone`, `DsCardTone`, `DsButtonVariant`, `DsChartRole`; назначения иконок централизованы в `DsIcons`.
3. Компоненты разрешают варианты в конкретные значения, владеют состояниями взаимодействия и внутренней компоновкой.
4. Композиции `DsPage`, `DsSection`, `DsPaymentSummary`, `DsHistoryGroup`, `DsCollapsingHeader` выражают назначение блока и устраняют повторение деталей компоновки в фичах.

Публичные параметры компоновки не принимают `double padding`, `double gap`, `double radius`, произвольную высоту или размер шрифта. Числа для значений графиков, идентификаторов мест, количества новых операций и индексов навигации — данные, а не геометрические настройки. Импорт `src/*` из приложения запрещён; автоматическую проверку визуальных литералов выполняет общий архитектурный инструмент репозитория.

## Владение отступами

| Компонент | Ответственность |
| --- | --- |
| `DsPage` | Закреплённая верхняя панель вне прокрутки, SafeArea, одна прокрутка, адаптивные поля страницы, ограничение читаемой ширины, footer. |
| `DsScaffold` | Общая постоянная навигация для форм и ленивых sliver-экранов; автоматический маршрутный возврат либо локальный `onBack`, согласованный с системной кнопкой Android. |
| `DsFilterBar` | Одна горизонтальная строка фильтров; при крупном тексте перенос без уменьшения зон нажатия. |
| `DsActionGrid`, `DsServiceCard` | Пары компактных действий на телефоне; при крупном тексте одна колонка. Вся сервисная карточка нажимается, без повторной кнопки «Открыть». |
| `DsConstrained` | Максимальная ширина содержимого на широком экране. |
| `DsPadding(inset: DsInset.*)` | Семантическая вставка; `horizontal` — поля списков без повторного вертикального интервала. |
| `DsColumn`, `DsRow`, `DsFlow` | Только промежутки между соседними детьми. Внешних полей нет. |
| `DsSection` | Заголовок, пояснение, действие и интервал перед содержимым. |
| `DsCard` | Внутренние поля, поверхность, радиус, обработка нажатия и контекст контрастного текста. Внешних полей нет. |
| `DsActionArea` | Отделённая область действий с SafeArea снизу. |
| `DsReadingSurface` | Прокручиваемое содержимое с доступным уведомлением поверх нижней части; уведомление не занимает место в slivers и не меняет позицию чтения. |
| `DsSliverContent`, `DsSliverInset` | Те же правила внутри CustomScrollView; собственная прокрутка не создаётся. |

Не нужно добавлять поля вокруг каждого ребёнка `DsColumn` или компенсировать двойные поля отрицательным смещением. Если композиция требует нового назначения интервала, меняется контракт общего пакета. Для большого списка используется ленивый sliver; `DsPage(children: ...)` предназначен для ограниченного числа секций и полей формы.

```dart
DsPage(
  title: 'Коммунальные услуги',
  children: [
    DsSection(
      title: 'Лицевой счёт',
      child: DsCard(
        child: DsColumn(
          children: [
            DsField(label: 'Номер счёта', controller: accountController),
            DsButton(label: 'Найти начисления', onPressed: search),
          ],
        ),
      ),
    ),
  ],
)
```

## Плотность и навигация после пользовательской проверки

Прежний дизайн отклонён пользователем 16 октября; направление и обязательства DS-23—DS-26 записаны в `requirements.md`. Ориентир — настроение и структура приложения Т-Банка: жёлтые основные действия, компактные белые поверхности, контрастная типографика и цветовые категории. Источники для поиска референса: [обновление приложения](https://www.tbank.ru/finance/blog/new-mb/), [официальные снимки интерфейса](https://www.tbank.ru/finance/blog/new-app-features/). Полные страницы и CDN из текущего окружения закрывали соединение; точное пиксельное совпадение с актуальной версией Т-Банка не заявляется.

Базовые интервалы, поля карточек и типографика задаются централизованно на шкале 4 dp. В обычном режиме строки операций имеют высоту 64 dp с внутренними вертикальными полями 8 dp; между соседними строками нет дополнительного gap. Иконка занимает 44 dp, название и подпись разделены 4 dp; дата группы отделяется интервалом 8 dp. Вся строка нажимается, область касания остаётся не меньше 48 dp. Длинное название в обычном режиме сокращается до одной строки; полное название сохраняется для озвучивания и экрана деталей. При росте текста строки и шапка получают дополнительное место, название — до двух строк, сумма переносится под подпись. Поля принадлежат композициям, визуальных чисел в фичах нет.

Строка `DsAccountRow` располагает название над балансом и номером: длинное название счёта не конкурирует с суммой за половину строки.

Постоянно компактная шапка была отклонена пользователем 17 октября. Главная использует развёрнутый `DsCollapsingHeader`: при offset=0 видны отдельные подписи, баланс 34 sp и оба быстрых действия; полная композиция занимает 192 dp при обычном тексте. `shrinkOffset` непрерывно меняет высоту до 64 dp и размер суммы до 20 sp. Уменьшение, скрытие подписей/действий и восстановление происходят только при прокрутке. При крупном тексте и переносах сумма и действия получают дополнительное место. Два `DsAccountCard` располагаются рядом через общий `DsActionGrid`; при крупном тексте — друг под другом. `DsCard` владеет компактными внутренними полями. Повторные крупные карточки аналитики и платежей на главной убраны.

Компактный заголовок списка использует `DsSection.density` и `DsInset.listHeader`; обновление остаётся доступным через иконку с tooltip и областью 48 dp. Загруженная строка и её placeholder имеют одинаковую высоту, чтобы выгрузка страниц не сдвигала чтение. Регрессия `home_density_test.dart` проверяет целиком видимые 3/2/4 операции на 360×720, 320×640 и 390×844 без прокрутки, выраженное развёрнутое состояние, промежуточное и полное сворачивание, восстановление, открытие деталей и возврат с нулевым смещением. Строки отдельно проверяются при 100%, 130%, 150% и 200% текста.

Заголовок `DsPage` больше не лежит в содержимом списка. `DsScaffold` предоставляет один постоянный AppBar. Без `onBack` он использует Navigator; с `onBack` возврат с панели и Android выполняет предыдущий логический шаг, оставляя маршрут и введённые данные. Детали операции и аналитики используют тот же каркас; самостоятельные «Штрафы» не оборачивают фичу второй панелью. Во время неопределённого платежа возврат не очищает журнал и не создаёт повторную оплату.

## Темы и бренд

`DsAppTheme.light(brand: DsBrand.bank)` и `.dark(...)` создают согласованные Material 3 темы. `DsBrand.fines` меняет акцент самостоятельного приложения через composition root. Фокус и курсор полей, выделение текста и индикаторы загрузки используют контрастный синий; выбранные жёлтые поверхности — чёрный текст. Подписи в фокусе и ошибке проверяются по фактическому отрисованному цвету в четырёх сочетаниях темы/бренда.

Светлая тема использует нейтральный светлый фон, чёрный текст и белые поверхности. Основной акцент — жёлтый; ссылки и вторичные действия — синие. Тёмная тема сохраняет жёлтый акцент и использует отдельные тёмные поверхности. Текст на жёлтом остаётся чёрным в обеих темах. Контрастный текст карточек автоматически наследуется `DsText` и `DsMoneyText`, включая их приглушённые подписи.

Цветовые слоты категорий `DsChartRole` постоянны между временным графиком, ранжированными полосами и их детализацией. Назначение слота категории выполняет фича; дизайн-система не сопоставляет бизнес-коды с цветами. Цвет сопровождается подписью, значением и порядковым номером.

Roboto Regular, Medium и Bold включены в пакет как семейство `DsSans` вместе с Apache 2.0 лицензией в `assets/fonts/LICENSE.txt`. Загрузка шрифтов из интернета отсутствует, включая web-просмотр: тема явно использует пакетное семейство. В golden-тестах загружаются те же лицензионные Roboto и Material Icons из установленного SDK, чтобы эталоны содержали читаемый текст, а не тестовый шрифт Ahem.

## Инфографика

`DsChartPoint` содержит `id`, `label`, неотрицательное числовое `value`, точную `displayValue`, необязательное пояснение `detail` и семантический цветовой слот. Компоненты вычисляют только пропорции рисования; итог, доли, суммы, сравнения периодов, валюта и округление отображаемого значения приходят от фичи.

Столбцы начинаются от нуля; явная подпись шкалы показывает максимальную границу. Выбранная точка получает точное значение в подсказке и текстовой панели. Нулевые точки подписаны нулём. Временной ряд с множеством точек прокручивается горизонтально, сохраняя доступную область нажатия, вместо сжатия всех дней в неразличимые полосы. Представление «Все значения списком» даёт те же действия и точные значения без графика. Ранжированные полосы сохраняют подпись, сумму, долю-пояснение и порядковый номер; порядок задаёт источник данных.

`onSelected(DsChartPoint)` — публичное действие фичи для детализации. Идентификатор выбранного элемента может контролироваться извне через `selectedId`, чтобы восстанавливать выбор при возврате. `updating` объявляет фоновое обновление без подмены значений вымышленными промежуточными суммами. Ошибка и первоначальная загрузка передаются стандартными компонентами состояния.

## Адаптивность и доступность

- Поля страницы, ширина чтения, адаптивная сетка и переносы выбираются по ограничениям родителя и системному масштабу текста.
- Заголовки секций с действиями перестраиваются в вертикальную группу при крупном тексте. Суммы используют адаптивную семантическую типографику и допускают перенос между группами тысяч; дробная часть и валюта остаются одной неделимой группой, исходная строка — в семантике. Нижняя навигация при крупном тексте использует два ряда с полными подписями.
- `headline` и `display` выбирают компактный семантический вариант типографики при узких ограничениях и крупном тексте. Системный TextScaler сохраняется целиком, исходная подпись не сокращается. `DsChoice` переносит длинную подпись и увеличивает высоту всей поверхности, сохраняя состояние выбора, фокус, клавиатурное управление и зону нажатия.
- Строка операции и её заглушка имеют одинаковую семантическую высоту, зависящую от масштаба текста. Вытеснение данных из кеша не сдвигает список. В строке длинный заголовок ограничен двумя строками; полная подпись доступна для озвучивания и на экране подробностей.
- Элементы действий имеют минимальную область нажатия; системный SafeArea и клавиатура учитываются каркасом.
- Графики, выбранные фильтры, результаты и строки содержат смысловые подписи. Исчезающие строки исключаются из семантики и hit testing.
- `MediaQuery.disableAnimations` отключает движение переходов и графиков. Компоненты истории останавливают текущую анимацию при включении этого параметра.
- Оболочка приложения отвечает за `TickerMode` неактивных вкладок и сохранение их жизненного цикла. Дизайн-система не запускает запросы или фоновые таймеры получения данных.

## Проверки и границы доказательства

`flutter test --no-pub` в пакете содержит 44 проверки. Помимо поведения компонентов, инфографики и анимации истории проверяются постоянный возврат после длинной прокрутки при 100%/200%, единая семантика Android back и верхней панели, отсутствие наложения суммы/действий в шапке при 100%/150%/200% и контраст текста выбранного жёлтого фильтра в обеих темах.

18 PNG-эталонов находятся в `packages/design_system/test/goldens` и `packages/bank_experience/test/goldens`: общие компоненты, главная, аналитика, графики, платежи и каталог в светлой/тёмной теме и с 200% текста. Светлый телефон дополнительно использует компактный viewport 360×720, близкий к рабочей области подключённого Android. Шрифты офлайн Roboto и Material Icons загружаются явно. Изменённые рендеры осмотрены; затем тесты выполняются без `--update-goldens`. Тест штрафов проверяет сохранение документа при возврате к результатам и отсутствие POST оплаты при системном возврате с подтверждения.

Эти проверки подтверждают компоновку и контракт поведения, но не доказывают FPS, задержку касания или память на бюджетном Android. Для этого обязательны профиль физического устройства и общий сценарий приёмки из `requirements.md`. Читаемость графиков и польза мотивированной анимации дополнительно проверяются человеком.


## Компоненты по пользовательским референсам

Главная и счёт используют `DsHomeHeader`, `DsAccountHeader`, `DsSliverPage`, `DsSliverSections`, `DsPanel`, `DsOverviewCard`, `DsShortcutBar`, `DsAccountProduct`, `DsBankCards`, `DsOfferBanner`, `DsImageOffer`, `DsRail`, `DsProductTile`, `DsLimitRow` и `DsQrCode`. Композиция и область применения описаны в [reference-design.md](reference-design.md). Новая главная заменяет прежний критерий числа строк истории на первом экране; старые снимки остаются историческими.

Панели имеют общий радиус 24 dp и поля 16 dp, секции — интервал 16 dp. Лента строит секции лениво, горизонтальные ряды — по видимым элементам. Размеры шапок 116→60 dp и 280→72 dp принадлежат DS; крупный текст увеличивает их, пары и быстрые действия перестраиваются в колонку. Декор счёта плавно закрывается однотонной тёмной поверхностью при сворачивании. `backEnabled` блокирует кнопку и системный возврат только во время подтверждённой отправки операции, без пустого обработчика.

Оригинальные PNG находятся в необязательном `bank_artwork`. Оболочка внедряет `DsArtworkSource`; приложение штрафов не подключает пакет изображений. Изображения декодируются по ширине отображения × DPR, максимум 1024 px. Свечение растровое, живого blur нет. Семантическая роль категории одинакова в обзорной полосе и аналитике через `spendingChartPoints` и палитру DS.

`DsReadingAnchor` отмечает содержимое операции внутри строки с меняющимся заголовком даты. После вставки записи дата может перейти к новой первой операции; координата читаемой операции при этом сохраняется. Ошибка в 25 dp воспроизведена и закрыта интеграционной регрессией `home_data_test.dart`.

Горизонтальные подборки и фильтры имеют обязательный семантический `id` и отдельный `PageStorageKey`; миниатюры карт используют стабильные идентификаторы карт. Они не наследуют численное смещение вертикальной ленты. Регрессия воспроизвела открытие новой подборки в конце (182,56 dp вместо 0); после исправления начальное положение и пользовательское горизонтальное смещение сохраняются независимо при удалении/восстановлении ленивой секции.

Страница счёта использует семантический режим `prebuildOffscreen: false`: нижеэкранные медиа не декодируются вместе с первым экраном. Тест проверяет отложенное построение и появление блока после прокрутки. Общий переход страницы сохраняет растровую поверхность, не смешивает целые экраны через alpha и округляет движение до физических пикселей.
