# ADR 0008: общий каталог строк и Accept-Language

Дата: 18 октября 2026 года. Языки: ru, en, uz. Подробности — в [localization.md](../localization.md).

## Решение и обоснование

- **Общий каталог.** `app_localizations` обслуживает все фичи и оболочки. Повтор, комиссия, ошибки платежа и категории не дублируются; переводчик работает с тремя файлами. `design_system` использует свой `DsLocalizations` и не зависит от продуктового пакета.
- **Коды в состояниях.** Cubit и домен возвращают перечисления и коды, экран выбирает текст. Язык меняется без перезагрузки состояния; логика тестируется без строк.
- **Серверные тексты.** Названия счетов, операций, начислений и отказы приходят по `Accept-Language`. Состояние демо-сервера языконезависимо, кеш ответов разделён по языкам. Категории и подписи графиков берутся из клиентского каталога, чтобы совпадать с UI и фильтрами.
- **Точные суммы.** `AppFormats` форматирует целые копейки/тийины символами `intl`, без `NumberFormat.currency` с `double`, чтобы округление никогда не меняло сумму.

## Ограничения

«Штрафы» включают весь каталог — несколько десятков КБ строк. Границы фич сохраняются: quality gate запрещает зависимость `fines_app` от банковских фич.

Решение пересматривается при добавлении письма справа налево — нужны RTL-проверки макетов — или реального backend со своим каталогом сообщений.
