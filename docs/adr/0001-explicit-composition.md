# ADR 1: явная композиция и независимые оболочки

Решение: Dart Pub Workspace, узкие domain-контракты, внедрение через конструкторы и отдельные composition roots. `bank_experience` включает банк и каталог, `app_foundation` содержит только общую инфраструктуру. Самостоятельные «Штрафы» импортируют свою фичу напрямую.

Причина: нужно доказать реальное выделение работающей фичи и сохранять прозрачные области жизни. Глобальные регистрации/модули не должны подтягивать весь банк.

Последствия: небольшой граф собирается явно без DI-контейнера и генерации. Публичный API, отсутствие циклов и транзитивные зависимости проверяются. При существенном росте графа выбор DI-библиотеки пересматривается отдельно.
