# ADR 3: семантический UI и движение непрерывности

Решение: визуальные числа и варианты живут только в design_system; экран выбирает семантические композиции. AST gate обнаруживает запрещённые конструкторы и числовые параметры, в том числе через локальные константы и выражения.

Причина: локальная подгонка геометрии разрушает переиспользование, брендинг, доступность и адаптивность.

Последствия: новый layout-вариант добавляется в общий API, а не экранную константу. Golden-тесты покрывают обе темы, 320px/200% текста. Движение истории сопоставляет только видимые стабильные ID, сохраняет опору и допускает прерывания. Польза движения проверяется человеком отдельно от технической корректности.
