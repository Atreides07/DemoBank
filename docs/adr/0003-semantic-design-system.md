# ADR 0003: семантический UI и движение истории

## Решение

Визуальные числа и варианты задаются только в design_system; экран выбирает семантическую композицию. AST gate проверяет запрещённые конструкторы и числовые параметры, включая локальные константы и выражения.

## Обоснование

Экранная подгонка геометрии нарушает переиспользование, брендинг, доступность и адаптивность. Новый layout-вариант добавляется в общий API.

## Ограничения и проверка

Golden-тесты покрывают обе темы, 320px/200% текста. Движение истории сопоставляет только видимые стабильные ID, сохраняет опору чтения и допускает прерывания. Пользу движения оценивает пользователь отдельно от технической корректности.
