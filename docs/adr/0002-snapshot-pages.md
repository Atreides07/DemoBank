# ADR 0002: snapshot-пагинация с ограниченными окнами

## Решение

Страница — 30 записей; сервер задаёт revision и непрозрачный cursor. В памяти — до пяти полных страниц. Стабильные ID/даты сохраняют адресацию посещённых слотов. Сервер возвращает согласованное окно вокруг anchor ID и страницу внутри фиксированной revision.

## Обоснование

Новые операции не должны создавать дубликаты, сдвигать чтение или требовать загрузки десятков страниц до далёкого якоря. Lazy-list сам по себе не ограничивает память моделей.

## Ограничения

История snapshot-версий на сервере ограничена; клиент обрабатывает истечение revision. Старые данные остаются до готовности нового окна, фоновые изменения применяются явно. Аналитика и детализация используют одну revision.
