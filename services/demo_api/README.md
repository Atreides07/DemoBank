# HTTP / HTTPS демонстрационный сервер

Запуск из корня монорепозитория:

```sh
dart run services/demo_api/bin/server.dart --host 127.0.0.1 --port 8080 --profile normal --seed 42
```

Профили: `normal`, `slow`, `unstable`, `offline`. JSON-обработчик, фильтры, пагинация, состояние платежей и постепенная доставка тела общие с локальным адаптером. Есть CORS для автономного web-просмотра. Для Android-эмулятора адрес хоста обычно `10.0.2.2`; физическому устройству нужен доступный адрес сервера и доверенный сертификат.

HTTPS поддерживается штатным TLS; отключение проверки сертификата в приложении не используется:

```sh
dart run services/demo_api/bin/server.dart --host 0.0.0.0 --port 8443 --profile slow --seed 42 --certificate /absolute/certificate.pem --private-key /absolute/private-key.pem
```

Сертификат и закрытый ключ предоставляет окружение; их не коммитят. Для локальной разработки можно использовать сертификат доверенного локального центра с корректным SAN. Публичный стенд требует домена и сертификата доверенного центра; успешная локальная TLS-проверка сама по себе не доказывает доступность внешнего стенда или доверие физического Android.

Автоматические проверки запускают настоящий HTTP-сервер на свободном порту, сравнивают JSON с локальным адаптером, проверяют CORS, затем создают временный TLS-сертификат, явно доверяют ему в тестовом клиенте и проводят HTTPS-платёж с потерей ответа и идемпотентным восстановлением. Для генерации временного сертификата нужен `openssl`:

```sh
dart test packages/network_simulation/test services/demo_api/test
```

Контракты и правила данных описаны в [пакете симулятора](../../packages/network_simulation/README.md).
