# Каталог дизайн-системы

Компоненты, темы, состояния и изолированный просмотр рабочих экранов.

SDK и разрешение зависимостей задаются корневым workspace. Из корня выполните `flutter pub get --enforce-lockfile`, затем из этой папки `flutter run`. По умолчанию используются встроенные моки; сервер и параметры запуска не нужны.

Полные команды, выбор HTTP/симулятора, проверки и ограничения приёмки: [README репозитория](../../README.md).
