# Штрафы

Самостоятельная оболочка, зависящая только от фичи fines и общих пакетов.

SDK и разрешение зависимостей задаются корневым workspace. Из корня выполните `flutter pub get --enforce-lockfile`, затем из этой папки `flutter run --dart-define=NETWORK_PROFILE=slow`.

Полные команды, выбор HTTP/симулятора, проверки и ограничения приёмки: [README репозитория](../../README.md).
